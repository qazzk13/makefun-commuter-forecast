A small Node program that writes one line of weather for Brindleford, a city I made up, to /output/entry.txt. It is the sort of forecast I would want to read half asleep at a bus stop: "Brindleford: fog until 8, then sunny and 19 degrees, small chance of ducks crossing by the market steps at lunch, so mind your shoes."

## Run it

```sh
node main.ts
```
